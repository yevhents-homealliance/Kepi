# kepi — HTML template

Мінімалістичний HTML/CSS/JS шаблон у стилі макету kepi.

## Сторінки
- `index.html` — головна
- `categories.html` — категорії
- `search.html` — результати пошуку
- `profile.html` — профіль майстра
- `chats.html` — чати
- `favorites.html` — обране

CSS та JS лежать у `assets/`.

Фото у демо підтягуються з Unsplash; для production замініть їх на власні локальні зображення.
